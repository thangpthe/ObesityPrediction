# Data directory

- `raw/`: place the original, unmodified source CSV files here.
- `processed/`: generated/derived datasets only. Do not treat these as raw inputs.
- Keep original source files read-only and record their source URL, license, retrieval date, checksum, and data dictionary.
- Do not commit sensitive personal/health data. Check the source license and repository visibility before adding datasets.

The current repository still has legacy files under `dataset/`. Do not move or overwrite them until their provenance has been verified.
